## Запуск
- Для запуска вам потребуется java (да, интерпретатор интерпретируется)
- [Скачайте](https://github.com/vankad24/aqua_lang_interpreter/archive/refs/heads/master.zip) и распакуйте архив проекта
- [Скачайте](https://github.com/vankad24/aqua_lang_interpreter/releases/latest/download/aqua.jar) jar архив и поместите его туда же
- Используйте `aqua.bat` для запуска или добавьте папку, где лежит .jar и .bat файлы, в path в переменные среды. Проверить можно командой `aqua --version`
- Чтобы запустить код, перейдайте путь до файла. Например `aqua main.aqua`. Примеры кода можно посмотреть в папке examples
- Для интерпретатора доступны следующие флаги:
  - `--debug` - вывод дополнительной информации
  - `--no-semantic` - запустить без семантического анализа. Почему бы и нет, если можно🤷‍♀️ 
  - `--version` - вывод текущей версии 
  - `--help` - вывод иформации, которая, возможно, поможет 

## Синтаксис

Примеры кода можно посмотреть в папке [`examples`](https://github.com/vankad24/aqua_lang_interpreter/tree/master/examples).

Список встроенных функций:
- print
- println
- readInt
- readFloat

## Подсветка синтаксиса в Sublime Text!

Чтобы добавить подсветку синтаксиса и запуск, из папки репозитория `SublimeTextPackage` скопируйте папку `Aqua` в папку `C:\Users\User\AppData\Roaming\Sublime Text\Packages`

Чтобы включить подсветку синтаксиса вручную, нажмите `View > Syntax > Aqua`

Если всё настроено правильно, вы можете нажать `Tools > Build` или `Ctrl + B`, чтобы запустить код
