## Запуск
- Вам потребуется java (да, интерпретатор интерпретируется😎)
- Скачайте и распакуйте архив
- Добавьте его в path или запускайте с указанием полного пути: 
`aqua main.aqua`
- Примеры кода можно посмотреть в папке examples

## Редактор
В качестве редактора вы можете использовать sublime text

Чтобы добавить подсветку синтаксиса и запуск, из папки реопзитория `SublimeTextPackage` скопируйте папку `Aqua` в папку `C:\Users\User\AppData\Roaming\Sublime Text\Packages`

Чтобы включить подсветку синтаксиса вручную, нажмите `View > Syntax > Aqua`

Если всё настроено правильно, вы можете нажать `Tools > Build`, чтобы запустить код
